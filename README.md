# Primo .exe — v0.2

Esercizio C++: inserisci una lista di numeri e ottieni media, somma, massimo e minimo.

Dalla **v0.2** il programma ha una interfaccia grafica: scrivi i valori separati da spazio, clicchi "Calcola" e leggi il risultato nella finestra.

## Versioni

Vedi [versions.md](versions.md) per il dettaglio e i download.

## File

- `primo_vettore_v0.2_gui.exe` — eseguibile Windows con interfaccia grafica, statico.
- `primo_vettore_v0.2_gui.cpp` — sorgente della v0.2.
- `primo_vettore_v0.1-alpha.exe` / `.cpp` — prima versione a riga di comando.

Compilato con Embarcadero Dev-C++ 6.3 (TDM-GCC 9.2.0).
