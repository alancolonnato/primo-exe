# Primo .exe

Esercizio C++: chiede quanti valori inserire, legge una lista di numeri interi e stampa media, somma, massimo e minimo.

## File

- `primo_vettore.exe` — eseguibile Windows, compilato in modo statico (non serve Dev-C++ per avviarlo).
- `primo_vettore.cpp` — sorgente corretto.

Compilato con Embarcadero Dev-C++ 6.3 (TDM-GCC 9.2.0).
