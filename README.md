# Primo .exe — v0.3

Esercizio C++ con interfaccia grafica: inserisci una lista di numeri separati da spazio, clicca "Calcola" e leggi media, somma, massimo, minimo e numero di valori.

Dalla **v0.3** la finestra si adatta a qualunque monitor: layout responsive, gestione del DPI e dimensione minima. Sullo sfondo volano gatti Nyan con scia arcobaleno.
