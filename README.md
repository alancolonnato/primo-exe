# Primo .exe — v0.4

Esercizio C++ con interfaccia grafica: inserisci una lista di numeri separati da spazio, clicca "Calcola" e leggi media, somma, massimo, minimo e numero di valori.

La **v0.4** corregge lo sfarfallio (double buffering e `WS_CLIPCHILDREN`), fa rimbalzare i Nyan cat sui bordi a velocità sostenuta e riproduce una musichetta chiptune in stile Nyan all'avvio. Il pulsante **Audio** la attiva/disattiva. La finestra si adatta a qualunque monitor (DPI e resize).

- `primo_vettore_v0.1-alpha.exe` / `.cpp` — prima versione a riga di comando.

Compilato con Embarcadero Dev-C++ 6.3 (TDM-GCC 9.2.0).
